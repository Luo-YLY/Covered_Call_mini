# 客户版命名与展示收口计划

本文档用于保留最终报告、展示 PPT 与 dashboard 改版时的命名安排。当前阶段只记录规划，不修改实验代码、数据口径或看板结构。

## 1. 总体原则

- 客户展示层使用投资研究语言，不直接暴露 `ver3`、`Step A/B/C/D`、`candidate`、`effective_zone` 等实验或代码命名。
- 内部留存层继续保留脚本名、CSV 字段名和策略 ID，作为数据溯源和复现实验的索引。
- 报告正文和 PPT 主体只展示客户版名称；附录、脚注或数据索引中再保留内部代码名。
- dashboard 在最终报告和 PPT 制作阶段一并改版，当前不单独改动页面文案。

## 2. 总标题与项目名称

客户版总标题建议：

```text
ETF备兑增强策略诊断与组合构建
```

客户版副标题建议：

```text
基于目标Delta、覆盖比例与回撤预算的多ETF备兑策略研究
```

内部项目名 `ver3.1 effective_zone_target_delta` 在客户材料中不作为标题出现，只保留在数据说明或附录。

## 3. 模块命名映射

| 内部名称 | 客户展示名称 | 用途 |
| --- | --- | --- |
| Step A / Single ETF sleeve diagnostic | 单资产备兑增强诊断 | 每个 ETF 单独判断备兑是否有效 |
| target-delta x coverage surface | 目标Delta x 覆盖比例参数图 | 展示策略参数空间 |
| BuyHold baseline | ETF裸持基准 | 作为所有备兑策略的基准 |
| candidate selection | 策略单元筛选 | 从单资产结果进入组合输入 |
| fixed weight portfolio | 固定权重组合 | 展示基础组合表现 |
| MDD-constrained Sharpe frontier | 回撤预算下的组合优化 | 展示最大回撤约束下的权重选择 |
| Step C robustness | 稳健性检验 | 展示相位、事件、成本、周期集中度 |
| Step D dynamic weighting | 动态权重配置研究 | 作为研究层，不直接替代主线 |
| sleeve | 策略单元 | 面向客户的统一称呼 |
| option leg contribution | 期权增强贡献 | 替代“期权腿收益” |
| assignment count | 被行权周期数 | 图表中写作“被行权周期数 / 总交易周期” |
| phase sensitivity | 调仓时点敏感性 | 替代“相位敏感性” |

## 4. 策略命名规则

内部策略 ID 不直接作为客户版主标题。例如：

```text
510300_DTE30_D40_Q70_Hold
```

客户版展示为：

```text
510300 目标Delta40 / 覆盖70 策略
```

正式报告表格可保留两列：

| 展示名称 | 内部代码 |
| --- | --- |
| 510300 目标Delta40 / 覆盖70 策略 | 510300_DTE30_D40_Q70_Hold |

正文优先使用展示名称；内部代码只在附录、数据索引或方法说明中出现。

## 7. Dashboard 后续改版安排

最终报告和 PPT 制作阶段，再统一修改 dashboard 文案与栏目名称。建议栏目如下：

1. 单资产诊断
2. 参数图谱
3. 策略单元筛选
4. 固定权重组合
5. 回撤预算优化
6. 动态权重研究
7. 稳健性检验
8. 数据说明

参数曲面区域建议统一改名为：

```text
目标Delta与覆盖比例图谱
```

BuyHold 基准面图下注释建议：

```text
黄色平面为ETF裸持基准，用于观察备兑策略是否在风险调整收益或回撤控制上形成改善。
```

## 8. PPT 章节建议

1. 研究目标：在ETF组合中引入备兑增强
2. 单资产诊断：哪些ETF适合备兑
3. 参数图谱：目标Delta与覆盖比例的有效区域
4. 策略单元筛选：从单资产到组合输入
5. 固定权重组合：基础组合表现
6. 回撤预算优化：约束最大回撤后的权重选择
7. 动态权重研究：是否值得引入动态配置
8. 结论：当前可用主线与研究层边界

## 9. 后续执行清单

- 在最终报告中替换实验/代码命名，正文使用客户版名称。
- 在 PPT 中采用同一套章节名、策略名和 ETF 展示名。
- 在 dashboard 改版时统一导航栏、图表标题、图下注释和表格列名。
- 保留内部代码名、CSV 字段名和脚本名，用于附录和复现说明。
- 在最终发布版中明确区分“可作为主线展示的策略单元”和“研究层观察结果”。
