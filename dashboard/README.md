# 最终研究看板

这是项目对外交接的唯一看板入口。页面不再按内部版本号组织，而是分为：

1. 组合研究：候选组合、净值、回撤、权重和稳健性证据。
2. 单 ETF 周期验证：权利金、行权或平仓扣减、净期权收益和上涨让渡。
3. 交接说明：当前研究结论、证据边界和接收方阅读顺序。

在仓库或最终交接包根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8765/dashboard/
```

`ver3/` 与 `ver4/` 路径仅作为内部可复现实现保留，不再作为对外交付名称。看板读取本地静态数据，不触发回测，也不访问外部接口。
