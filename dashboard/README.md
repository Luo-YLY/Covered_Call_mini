# 最终研究看板

这是项目对外使用的唯一看板入口。页面不再按内部版本号组织，而是分为：

1. 组合研究：候选组合、净值、回撤、权重和稳健性证据。
2. 单 ETF 周期验证：权利金、行权或平仓扣减、净期权收益和上涨让渡。
3. 数据与回测：提交新的ETF原始数据、控制回测区间、预览并发布动态结果。
4. 项目说明：当前研究结论、证据边界和接收方阅读顺序。

右上角“查看原始数据”进入 `dashboard/raw-data/`。该页把行情输入、研究输入、组合研究底表和单 ETF 周期账本按用途整理，并全部使用相对路径链接；交接包移动或改名后仍可访问。

在仓库或最终交接包根目录运行：

```powershell
python scripts\serve_dashboard.py --port 8765
```

然后访问：

```text
http://127.0.0.1:8765/dashboard/
```

`ver3/` 与 `ver4/` 路径仅作为内部可复现实现保留，不再作为对外产品名称。“数据与回测”将看板已有ETF和新增ETF统一展示，并使用本地服务运行隔离回测，不访问外部接口。完整研究至少需要12个可闭合且可实际选出期权的月度周期；运行会生成净值、回撤、逐期账本、现金流、情景归因和审计记录。用户可在“单ETF周期验证”主页直接运行并查看目标Delta、ATM或OTM结果；确认保存后下次打开仍会保留。“组合研究”的“自选组合”页在共同月度周期上按月末固定权重再平衡，并以ETF和所选期权的日收盘生成日频MTM净值；缺失期权报价时沿用最近收盘且必须披露覆盖率，月末结果与周期结算对账。
