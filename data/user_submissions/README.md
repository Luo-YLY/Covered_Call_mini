# 用户提交ETF数据

该目录由统一看板的“添加ETF”功能在本机写入。

每次提交均使用独立目录，保留ETF日行情、期权合约、期权日行情三份原始CSV，以及标准化行情、Delta派生表和 `manifest.json`。数据来源不限，ETF元数据不是必填项。

用户提交不会覆盖项目既有的 `data/raw/`、`data/source/` 或研究输出。完整研究要求至少12个可闭合且可实际选出期权的月度周期；数据不足仍会保存，但显示为“待补数据”。通过校验后，可在看板中设置回测区间并生成净值、回撤、逐期账本、固定名义本金现金流、情景归因和审计预览；只有用户确认发布后，结果才写入独立的 `outputs/user_backtests/` 并进入“单ETF周期验证”的选择器。除本说明文件外，运行时提交内容默认不纳入 Git。
